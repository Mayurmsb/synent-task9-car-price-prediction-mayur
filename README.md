## 📌 PROJECT OVERVIEW

The objective of this project is to build a complete End-to-End Machine Learning project using a real-world Used Car Dataset.

This project includes:

- Data Collection  
- Data Cleaning  
- Exploratory Data Analysis (EDA)  
- Feature Engineering  
- Model Building  
- Model Evaluation  
- Deployment using Streamlit  

---

## 📂 DATASET DETAILS

- **Dataset Name:** Used Car Dataset  
- **Total Rows:** 6019  
- **Total Columns:** 13  

### 📌 Features Used:

- Name  
- Location  
- Year  
- Kilometers Driven  
- Fuel Type  
- Transmission  
- Owner Type  
- Mileage  
- Engine  
- Power  
- Seats  
- Price
